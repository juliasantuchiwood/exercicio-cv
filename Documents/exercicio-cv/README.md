# Git Your Career - Versionamento de CV

Este repositório foi criado como parte de um exercício acadêmico para demonstrar o uso prático de versionamento de código com Git e GitHub.

## Objetivo
O projeto contém a evolução do meu currículo, partindo do meu perfil atual como graduanda e projetando minhas metas para daqui a 5 anos, com foco em Astrofísica Nuclear, nucleossíntese estelar e aplicação de Ciência de Dados (Python).

## Histórico de Commits
O repositório atende ao requisito de utilizar 3 ou mais commits para simular essa evolução profissional de forma estruturada.
